Local email archive software

Ingest, preserve, search, and report on email archives.

Mail Archiver reads supported email files, stores the original message data in MBOX files, records where each message came from, and builds a local search index.

Users

For personal and institutional email collections.

The program uses the same archive format and search interface for both kinds of collection.

For Individuals

Consolidate exported email.

Read supported email files from old computers and backup drives into one local archive, then search the combined collection.

  • Store original message data in MBOX files
  • Search across accounts and backup sets
  • Verify files and messages with SHA-256 hashes

For Archivists

Process donor email collections.

Library staff can use the local viewer to search the collection and preview messages and attachments. Reports provide data that can be used in finding aids.

  • Export a BagIt 1.0 / Mailbag 1.0 package
  • Record where each message was found
  • Transfer MBOX files to ePADD
