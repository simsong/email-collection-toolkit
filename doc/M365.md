# Microsoft 365 acquisition

The project imports local PST with the Rust helper and best-effort OST with
the external libpff converter. It has no Microsoft Graph or OAuth IMAP adapter,
and does not import Outlook for Mac OLM. The password-based generic IMAP CLI
does not implement Microsoft modern authentication.

## Local export and cache paths

Use an Outlook export supported by your client and account, preserving the
original file. Record the client/version, synchronization range, selected folders
and item counts. An export of a local cache does not prove server completeness.
See Microsoft's [Outlook export guidance](https://support.microsoft.com/office/export-or-back-up-email-contacts-and-calendar-to-an-outlook-pst-file-14252b52-3075-4e9b-be4e-ff9ef1068f91).

[PST_IMPORTER.md](PST_IMPORTER.md) owns reader prerequisites, reconstruction
limits, diagnostics and partial-import behavior. Complete synchronized Apple
Mail `.emlx` records offer another best-effort local path;
[APPLE_MAIL_CACHE.md](APPLE_MAIL_CACHE.md) owns its safety and completeness limits.

## Deferred live acquisition

Graph and OAuth IMAP require a future maintainer-owned public-client registration
and account/tenant consent. Tokens must remain local in the OS credential store.
Tenant policy and publisher verification must be checked at implementation time,
using Microsoft's [Graph permissions](https://learn.microsoft.com/graph/permissions-reference)
and [IMAP OAuth guidance](https://learn.microsoft.com/exchange/client-developer/legacy-protocols/how-to-authenticate-an-imap-pop-smtp-application-by-using-oauth).
No current registration, consent command or end-to-end provider acceptance is
implied by this design.
